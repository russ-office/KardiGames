KardiGames — site template (static hosting)

FOLDER STRUCTURE
- index.html        (launcher)
- games/            (put your HTML games here)
  - .keep           (placeholder so the folder exists in the zip)

HOW TO USE
1) Put your 5 game HTML files into ./games/ and RENAME exactly:
   - dots_and_boxes_OX_10x10_offline_v2.html
   - Jumping_Ball_Runner.html
   - snake_js_dynamic-2.html
   - space_invaders_mono_pyscript-5.html
   - spasi-mini-nyash.html

2) Upload entire folder to a GitHub repository (via Add file → Upload files).
3) Enable GitHub Pages (Settings → Pages → Deploy from a branch → main / (root)).
4) Share the Pages URL. Clicking a card opens a game, the HTML chip downloads it.
